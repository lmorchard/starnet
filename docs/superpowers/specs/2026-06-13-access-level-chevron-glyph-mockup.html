Access-level chevron glyph — inspector header APPROVED: Treatment A

Companion mockup archived from the 2026-06-13 brainstorming session. Three stacked chevrons, reached levels lit in the current level's hue, unreached dim — shown in the real GRADE · ACCESS · ALERT row beside the alert lamp on the game's #0a0a0f background. Treatment A (unified color) was selected. Treatment B (per-tier hue) is recorded below for context.

A · UNIFIED — all lit chevrons share the current level's color (SELECTED)
GRADEC· LOCKED· GREEN
GRADEC· OPEN· YELLOW
GRADEC· OWNED· RED

A · Unified color

The whole badge takes on the current level's hue (teal→blue→green-teal). Count shows progress; one color reads cleanly at 16px. Matches how the tick-meter colors all lit ticks one tier color.

B · PER-TIER — each chevron has a fixed hue; dim until reached (not selected)
GRADEC· LOCKED· GREEN
GRADEC· OPEN· YELLOW
GRADEC· OWNED· RED

B · Per-tier hue

Bottom chevron always teal, middle always blue, top always green-teal — the "frontier" is where it goes dim. More information per glance, but busier and the ramp is subtle at 16px.
