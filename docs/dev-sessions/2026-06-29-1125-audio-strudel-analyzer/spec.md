# Audio-reference: emit Strudel (analyzer + minimal Strudel player) Spec

**Goal:** Re-target the audio-reference analyzer to produce idiomatic, human-editable **Strudel code** as the playable artifact (instead of Tone-shaped `score_spec`), and replace the Tone player with a **minimal Strudel player** that plays / edits / saves that code — so a reference track becomes Strudel a person (or a Strudel-literate contributor) can read, tweak, and hear.

**Source:** User request 2026-06-29, following the Strudel+superdough spike (`tmp/strudel-spike/`, see memory `strudel-superdough-spike.md`). Relates to #248–#252.

## Current state

The analyzer is a clean pipeline (`research.md`): audio → librosa MIR (`mir.py:45`) → `build_prompt` (`prompt.py:135-205`) → forced-structured Gemini call against `RESPONSE_SCHEMA` (`gemini.py:45-56`, schema `prompt.py:62-132`) → `build_sidecar`/`assemble_stems` (`scorespec.py:34-69`) → `docs/{slug}.json` + `.md` + index.

The sidecar already has **two layers**: an engine-agnostic `interpretation` (`summary`, 7-dim `vocabulary`, per-track `instrument`/`pattern`/`description` prose, `score_draft`) and a **playable projection** `score_spec`. The Tone-ness lives only in the playable part: `Track.synth` (`SynthSpec{type∈PALETTE, options}`, `schema.py:83-86`) + `Track.steps` (`{grid, notes[]}`, `schema.py:88-91`). The browser player (`player/player.js`) is 100% Tone (PALETTE, `expandOptions`, `triggerStep`, DSP pools, reverb bus). `/save/<slug>` replaces only `score_spec` (`save.py:12-16`). Corpus = 11 Tone-shaped tracks regenerated by `docs/dev-sessions/2026-06-26-1251-reduce-instrument-count/rerun_all.sh`.

## Desired end state

**Analyzer.** Per track, the LLM emits a `strudel` code string (idiomatic Strudel: `note(...)/sound(...)` + mini-notation + `.lpf/.room/.gain/...`) **instead of** `synth`+`steps`. The prose interpretation layer is unchanged. The prompt carries a curated, version-pinned **Strudel reference** (supported functions + the exact sound names available in our `@strudel/web` setup). A **node-based eval validator** confirms each generated `strudel` string transpiles and produces events before it's written.

**Sidecar.** `score_spec.tracks[]` carry `strudel` (string) in place of `synth`/`steps`; everything else (name, instrument, pattern, description, stem tag, root/mode/bpm) stays. The per-track Strudel strings are the editable source of truth — **no compiler**, no structured→code transform.

**Player.** A minimal Strudel player replaces the Tone player: library → load sidecar → one editable code box **per track** (replacing the synth-knob card) + mute/solo → **Play** assembles `stack(<non-muted track code>)` and runs it via `@strudel/web`'s `evaluate()` → **Save** persists edited per-track `strudel` via `/save`. The old Tone player is **preserved as a renamed reference artifact** (e.g. `player/tone-player.{js,html}`), still served, not deleted.

**Corpus.** Rebuild a **reduced 3–5 track** corpus as Strudel (not all 11). Vertex calls use GCP project `moz-fx-future-products-nonprod` (memory `vertex-gcp-project.md`).

## Design decisions

- **Decision:** LLM emits Strudel code directly (code-as-field in structured output); the code is the single editable source of truth.
  - **Why:** Idiomatic human-readable Strudel serves the hacker/livecoding aesthetic and possible Strudel-literate contributors; Les will hand-edit after generation.
  - **Rejected:** Structured fields compiled to Strudel — a compiler can't round-trip hand-edits back to structure, so regen would clobber edits (the Stripdown overwrite pain). Also rejected full-docs RAG for the reference (overkill for a bounded DSL subset).

- **Decision:** Inject a curated, version-pinned Strudel reference (functions + available sound names) into the prompt.
  - **Why:** Gemini's Strudel knowledge is assumed partial/stale; a bounded in-context reference is deterministic, testable, pins to our embedded `@strudel/web` version, and prevents referencing sounds we don't have.
  - **Rejected:** Trusting model knowledge blind; RAG.

- **Decision:** Validate generated Strudel by headless node eval (transpile + query one cycle for events), shelled out from the Python tool.
  - **Why:** Strudel's pattern engine (`@strudel/core/mini/transpiler`) is pure JS and runs headless without audio; catches hallucinated API before write.
  - **Rejected:** Browser/Playwright validation (heavier); no validation (the tool's discipline is reproducibility).

- **Decision:** Per-track Strudel strings, assembled into a `stack(...)` at play time.
  - **Why:** Preserves stems tagging, per-track editing, and mute/solo (toggle a track out of the stack). Stack-assembly is trivial string-wrapping, not a semantic compiler — code stays the truth.
  - **Rejected:** One monolithic program string (loses per-track structure/mute).

- **Decision:** Replace the Tone player; preserve the old one as a renamed reference artifact; rebuild a reduced 3–5 track corpus.
  - **Why:** One-engine direction; a Strudel player is simpler (no synth knobs/DSP pools/recycler). Keeping the Tone player as reference avoids losing the prior work; reduced corpus keeps regen cost/iteration small.
  - **Rejected:** Parallel two-player maintenance; deleting the Tone player; full 11-track regen up front.

- **Decision:** First execute step is an empirical de-risk — generate one Strudel snippet from a described sound and eval it — before committing the full pipeline.
  - **Why:** Cheaply gauges baseline model knowledge; informs how heavy the reference needs to be.

## Patterns to follow

- Prompt + schema assembly: `prompt.py:62-132` (RESPONSE_SCHEMA), `:135-205` (build_prompt), per-stem `:208-216`. Swap track `synth`+`steps` → `strudel`; add the reference block.
- Sidecar assembly: `scorespec.py:24-41` (`build_score_spec`/`build_sidecar`), `:44-69` (`assemble_stems`). Keep structure, change per-track playable field.
- Schema typedefs: `schema.py:59-101` — replace `SynthSpec`/`SynthOptions`/`Steps` usage on Track with a `strudel: str`.
- Save: `save.py:12-16` `apply_score_spec` already replaces `score_spec` wholesale — per-track `strudel` edits ride this unchanged.
- Player scaffolding to reuse (library, `/save` POST, per-track cards, mute/solo, window-focus pause): `player/player.js` — keep the shell, swap card internals (code box) + the play path (spike's `initStrudel`/`evaluate` from `tmp/strudel-spike/index.html`). Spike gotchas in memory `strudel-superdough-spike.md` (async global registration → poll; `evaluate()` not `new Function`; dirt-samples stream from github).
- Tests asserting output shape that must change: `test_prompt.py` (schema requires strudel + reference present), `test_scorespec.py` (PALETTE/steps → strudel field), `test_render.py` (markdown shows strudel), `test_save.py` (persists strudel).

## What we're NOT doing

- **No structured→Strudel compiler** and no round-trip from edited code back to a structured form.
- **Not deleting the Tone player** — renamed/moved + still served as reference only (no new features on it).
- **Not regenerating all 11 corpus tracks** — 3–5 to start.
- **Not adding per-track synth/effect knob UIs** to the Strudel player — editing is via the code box. (Live timbre tweaking in Strudel terms is a later concern, ref #248/#252.)
- **Not changing the MIR/librosa extraction, stems separation, or the prose interpretation layer.**
- **Not touching the game's own audio engine** (the shipped Tone music/SFX) — that's a separate future arc; this session is the analyzer tool only.
- **Not building Strudel-side reactive/generative control** (the `signal()`/game-event bridge) — spike-proven, out of scope here.

## Open questions

- **Sidecar field name + whether to also store an assembled `program`.** *Default:* per-track `strudel: str` only; the player assembles `stack(...)` at play time (don't persist a redundant assembled copy that could drift). Revisit if the player needs a single saved program.
- **Exact supported-sound list + Strudel function subset for the reference.** *Default:* enumerate empirically from our `@strudel/web@1.0.3` setup during execute (synth sounds via `registerSynthSounds` + dirt-samples); the curated reference is authored from that enumeration. Not a planning blocker.
- **Reduced corpus tracks** — *resolved:* see the Corpus section (Agent Side Grinder Stripdown, Dry Blood/Parallels, The Knife — Heartbeats; source `.mp3`s in `~/Downloads`).
- **Validator depth.** *Default:* transpile + `queryArc` one cycle, assert ≥1 event and no throw; richer musical checks deferred.
